G4 C and seed-noise rule (eval_g4), written 2026-10-31T11:37:41+07:00 before any RKNNLite INT8 or FP16 mAP result of baseline seeds 1 and 2 and before any result of ReLU exists (FP32 PyTorch results of seeds 1 and 2 from training already exist, descriptive only). Not from a source. Not reviewed by the user (goal of 2026-10-31, phase 2). The number 1.0 pp (approved 2026-10-25, page 01-operator-support section 2) is the only threshold. Everything else here is new and unreviewed.
Questions: G4C (ReLU against SiLU accuracy) and G4N (how large the seed-to-seed spread is, to read the 1.0 pp margin on css_test with 82 images).
Models and calibration: baseline SiLU seeds 0, 1, 2 (ppe5_yolov8n_baseline_100ep_s{0,1,2}) and ReLU seed 0 (ppe5_yolov8n_relu_100ep_s0). Every INT8 model is built with the calibration list of baseline seed 0 (export_npu.py --calib-from ppe5_yolov8n_baseline_100ep_s0). Identity proof: stems_md5 (md5 of the sorted stems joined by newline) and png_md5 (md5 of the sorted 'name sha256' lines of the PNG files), computed for seed 0 on 2026-10-31 as 11d6a5c69414a6eafd8b98f99724b0b2 and 6652576adb7608ddf8ff326c57851732, equal in seeds 1 and 2, plus the basenames of rknn_int8/dataset.txt equal line by line. The md5 of dataset.txt itself is not a proof, since it holds absolute paths that contain the run id. Baseline seed 1 INT8 therefore replaces its older export (renamed rknn_int8_ownlist, used by X5). The existing seed 0 INT8 export is untouched. FP16 has no calibration.
Method: make evaluate RUN=<run> BACKEND=rknn PREC=int8|fp16 BOARD=minhnhat@192.168.137.49 (Evaluation Protocol v1, RKNNLite on the board, same code as X7 and X7b) for css_test (82 images, the gate set, 41 NoHelmet instances) and ppe2286_ext (180 images, descriptive). FP32 PyTorch (make evaluate BACKEND=pt) is run for every run and set that lacks it and is descriptive only. The script refuses to score on a model sha256 mismatch or a missing image.
Statements (css_test, per dtype INT8 and FP16, and for the AP50-95, AP NoHelmet, AP Vest columns):
S-N1 spread over seeds 0, 1, 2 of the baseline: minimum, maximum, range = max minus min, in pp. The 1.0 pp margin is labelled 'trong nhiễu seed' only when the range of that column is at least 1.0 pp, and 'ngoài nhiễu seed' only when the range is below 1.0 pp. Three seeds, so no standard deviation is a conclusion, the sample standard deviation (ddof 1) is reported next to it.
S-C1 gate C for the ReLU candidate (INT8, the conclusion dtype): difference ReLU seed 0 minus SiLU seed 0 in pp for AP50-95, AP NoHelmet and AP Vest. C passes only when all three differences are at least minus 1.0. It fails when any is below minus 1.0. The same differences for FP16 are a reference and do not decide. FP32 differences are descriptive. Every ReLU result carries the label '1 seed'.
S-C2 whether a ReLU difference lies inside the S-N1 spread of the same column is stated next to S-C1, as description, it does not change S-C1.
Limit: ReLU is initialised from the SiLU yolov8n.pt weights (ai/models/yolov8n_relu/yolov8n_relu.py), as the SiLU baseline starts from yolov8n.pt. Seeds 1 and 2 of the baseline only measure the training spread of SiLU, the ReLU training spread is unknown (1 seed).
The runs happen when no timing measurement runs on the board (one job at a time). Budget: experiment 1 for G4C and G4N. Re-run only if the model on the board differs or the script aborts.
